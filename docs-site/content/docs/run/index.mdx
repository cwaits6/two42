## What you run

two42 is open source under AGPL-3.0, so a church can host its own copy. A running install has four parts:

- **The app.** A Next.js server, built from this repository. The hosted service runs on Vercel; any host that runs a Next.js server will do.
- **A Supabase project.** Postgres with row-level security, Auth for sign-in, and Storage for photos. The schema, its policies and the job schedules all come from the migrations in `supabase/migrations/`.
- **Three edge functions.** Event reminders, serving reminders and a nightly clean-up, run on a schedule by `pg_cron` inside the database.
- **Resend.** Sends the app's email: invites, setup links, approvals, serving emails and reminders. Password-reset emails come from Supabase Auth instead, through the SMTP sender you configure there.

Google Maps is optional. Without a key, event locations are plain text.
