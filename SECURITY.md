# Security

To report a security problem in two42, email [security@two42.io](mailto:security@two42.io) with what you found and how to reproduce it. Please don't open a public issue, and don't touch real members' data while looking into it.

This covers the hosted service at two42.io and the code in this repository.

If you run your own install, it's yours to run: its hosting, updates and data are your responsibility. Replace the contact in this file and in [`public/.well-known/security.txt`](public/.well-known/security.txt) with your own, so reports about your install reach you.
